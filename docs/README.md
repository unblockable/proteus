# README

This directory documents the usage and deployment of Proteus.

- To run Proteus as tor bridge, please read ['tor_bridge_setup.md'](tor_bridge_setup.md)  
- To run Proteus as tor client, please read ['tor_client_setup.md'](tor_client_setup.md)
- To run Proteus as a standalone proxy server, please read ['standalone_proxy_setup.md'](standalone_proxy_setup.md)
- To run Proteus as a standalone client proxy, please read ['standalone_client_setup.md'](standalone_client_setup.md)
- To run Proteus as a client directly via CLI, please read ['tor_socks_client.md'](tor_socks_client.md)
- To run Proteus as a client via Termux in mobile, please read ['mobile_phone_setup.md'](mobile_phone_setup.md)
